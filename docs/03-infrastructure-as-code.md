# ☁️ 03: Infrastructure as Code (Azure AI & Copilot Studio Integration)

Many enterprise Copilot Studio agents are not standalone; they rely on supporting Azure infrastructure for enterprise grounding (RAG), vector indexing, secret management, and model orchestration.

## 🚀 Provisioning Azure Resources via Bicep

The files in `infrastructure/bicep/` deploy:
1. **Azure OpenAI Service:** Hosts model deployments (e.g. `gpt-4o`, `text-embedding-3-large`).
2. **Azure AI Search (Cognitive Search):** Hybrid semantic + vector search index.
3. **Azure Blob Storage Account:** Document storage for enterprise knowledge files.
4. **Azure Key Vault:** Securely stores API keys, connection strings, and certificates.
5. **Role-Based Access Control (RBAC):** Assigns `Cognitive Services OpenAI User` and `Storage Blob Data Contributor` to Copilot Studio service principals.

### Deployment Commands

```bash
# Login to Azure
az login

# Set active subscription
az account set --subscription "Your-Subscription-Id"

# Deploy resource group and Bicep template
az group create --name rg-copilotstudio-prod --location eastus

az deployment group create \
  --resource-group rg-copilotstudio-prod \
  --template-file infrastructure/bicep/main.bicep \
  --parameters environmentName=prod location=eastus
```

## 🔗 Connecting Copilot Studio to Azure OpenAI & AI Search

Once the Azure resources are deployed:
1. Open your Copilot in **Copilot Studio**.
2. Go to **Knowledge** -> **+ Add knowledge**.
3. Choose **Azure OpenAI on your data** or **Azure AI Search**.
4. Supply the Search Endpoint, Index Name, and Azure OpenAI Resource Endpoint generated by the IaC templates.
