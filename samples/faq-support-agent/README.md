# Retired illustrative sample

The old hand-authored `Other` and `src` files were not a valid Dataverse export
or a verified topic schema. They have been removed rather than leaving a fake
solution payload or a message that claimed a ticket had been dispatched without
a backend.

Start with the editable [IT FAQ agent](../it-faq-agent/README.md) or
[ticket intake agent](../ticket-intake-agent/README.md). Each maps files to actual
UI surfaces; neither is a whole-agent/solution import or a tenant-tested package.

For deployment, build the agent in Dev and export a genuine solution using the
[ALM guide](../../docs/02-alm-and-automation.md). Do not pack this folder.
